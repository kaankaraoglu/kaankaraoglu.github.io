# kaankaraoglu.github.io

Personal website for Kaan Karaoglu, hosted on GitHub Pages.

## Structure

- `index.html` — Single-page site
- `css/styles.css` — Stylesheet
- `assets/` — Favicon and resume PDF

## Development

No build step or dependencies required. To run a local dev server:

```sh
# Python
python3 -m http.server 8000

# Node
npx serve
```

Then open [http://localhost:8000](http://localhost:8000).

## Deployment

Automatically deployed via GitHub Pages on push to `main`.
